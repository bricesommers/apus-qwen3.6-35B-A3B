# tests/m4b — golden-reference oracle for the M4 single-layer forward

Milestone M4b, Qwen3.6-35B-A3B: `tools/oracle.py` is a numpy-only port
of ONE decoder layer of each kind (docs/M4-CONTRACT.md sections 2–5),
generating the deterministic fixtures (`tests/m4b/fixtures/`) that the
C single-layer forward (M4c) is verified against, plus self-checks
(`check_oracle.py`).

Run:

```
.venv/bin/python tests/m4b/gen_fixtures.py   # regenerate fixtures/ deterministically
.venv/bin/python tests/m4b/check_oracle.py   # all checks must pass (exit 0)
```

numpy only, fixed seeds (weights 20260829, inputs own stream 20260829).
The oracle is written directly from the HF reference
(`reference/modeling_qwen3_5_moe.py`: RMSNorm 878-895, RMSNormGated
175-192, causal conv1d 207-247, l2norm 250-255, recurrent gated delta
rule 395-455 — THE contract, the chunk path 258-392 is NOT bitwise
equal and is NOT used, GatedDeltaNet mixer 458-618, RoPE 91-171/621-664,
eager attention/repeat_kv 667-701, gated GQA 704-778, experts/router/
MoE 781-875, decoder wiring 898-954) — deliberately NOT from the C
sources, so generator and C cannot share a consistent-but-wrong
convention (the Apus M4c lesson; `check_oracle.py` additionally
consumes only weights read back from disk, never the generation
arrays).

## Two numeric modes

- **f32 (dtype-faithful, the C target)** — bf16 rounding (RNE via the
  candidate-distance oracle, independent of the C bit-trick) at every
  contract point, fp32 storage where the contract keeps fp32 (router
  softmax, attention softmax input, GDN decay/recurrence/state,
  l2norm, norm variances), matmuls accumulated in f64 and rounded to
  the storage dtype (a deterministic, platform-independent "ideal fp32"
  realization).
- **f64 (truth)** — same algorithm, all arithmetic in float64, no bf16
  rounding. The per-stage |f32−f64| envelope (fixtures `envelope.txt`)
  is the scale the C forward must land inside of.

Documented realization choices (reorder classes, absorbed by the
envelope, NOT semantic deviations): MoE routed-expert weighted sum
accumulated fp32 with a single bf16 round (HF index_add_ into a bf16
buffer rounds per expert); torch fp32 tree reductions realized as f64
sequential sums then st(); softplus == logaddexp(0,x) incl. the x>20
branch; router top-k tie-break lowest index wins.

## Layer kinds and mini-config

`gdn` = Gated DeltaNet + MoE (layer_types "linear_attention");
`full` = gated GQA full attention + MoE ("full_attention"). MoE on
EVERY layer (no dense layers). Fixture dims preserve every structural
feature (oracle MINI_CFG): hidden 128; GDN 4 K heads / 8 V heads × 32
(repeat ×2), conv k=4 fused over the 384 [q|k|v] channels, A_log and
dt_bias fp32, per-head l2norm (fp32 out, q ×= 32^-0.5), RMSNormGated
direct-weight output norm; full attn 4 q heads / 2 KV heads × 64,
partial rotary 16 (factor 0.25), θ=1e7 NeoX, per-head (1+w) q/k norms
before RoPE, elementwise sigmoid output gate; MoE 16 experts top-4
(fused gate_up), sigmoid-gated shared expert 32. (1+w) norm weights
generated as N(0, 0.1) codes; the GDN output norm as 1+N(0, 0.1)
(direct).

Sequences per kind: prefill_len 7 (state fixtures afterwards) + 5
decode steps with carried state (positions 7..11). Stage goldens (both
modes) for every named intermediate: common `ln1 attn_out res1 ln2
out`; GDN `qkv_conv beta gdecay rec_o onorm`; FULL `qf kf attno
mgate`; MoE `rtr_idx rtr_w moe_routed moe_shared moe_out`.

State fixtures: the GDN conv state as bf16 codes (**the oracle's [C,K]
state is sliced to its last K−1 columns — the C kernel stores the last
3 pre-conv inputs; the oracle's first column is shifted out before
ever being read**), S as fp32, the FULL KV caches as bf16 codes, pos
as i64.

## Self-checks (check_oracle.py)

1. **Replay** — re-running the layer from disk-loaded weights
   reproduces every stored golden exactly (IO integrity +
   determinism).
2. **Selection identity** — router f32 == f64 selections on every
   token (fixture margins dwarf the f32/f64 realization noise; if this
   ever fails, the input seed must change, not the tolerance).
3. **Chunk invariance (oracle-side)** — one-shot T=12 vs 7+5: f64
   exact (measured 0); f32 zero bf16 code flips (measured 0/1536 both
   kinds — the oracle realization is identical between paths by
   construction).
4. **Envelope table** — printed and written to `envelope.txt`;
   measured max-abs |f32−f64| per stage runs 3e-4–3.3e-2 (0.09%–1.2%
   rel), with the fp32-valued gdecay at 2.4e-2 abs (8.7e-4 rel).

## Files

- `tools/oracle.py` — oracle implementation (op ports, layer forward,
  weight generation, state; MINI_CFG).
- `tests/m4b/gen_fixtures.py` — deterministic fixture writer.
- `tests/m4b/check_oracle.py` — self-checks (exit 0 = green).
- `tests/m4b/fixtures/` — generated weights/inputs/goldens/states
  (regenerated by `make golden-m4b` / `make test-m4b`).
