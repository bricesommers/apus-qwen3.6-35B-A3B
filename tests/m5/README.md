# tests/m5 — full mini-model forward + sampling, verified end-to-end

Milestone M5: the complete forward — embedding → N decoder layers (typed
by the config's `layer_types`) → final RMSNorm → lm_head → bf16 logits
widened to FP32 → sampling — in C11 (`c/st.h`, `c/model.h`, `c/sample.h`,
`c/apus-qwen.c`), verified against the numpy oracle (`tools/oracle.py`
`full_forward`) on a synthetic full mini-model. Builds on M4c (per-layer
stage verification) unchanged.

Run:

```
make apus-qwen     # the CLI binary (bin/apus-qwen)
make test-m5       # 81 checks + CLI smoke, exit 0 iff all pass
make ubsan-m5      # same under -fsanitize=undefined
make golden-m5     # regenerate tests/m5/fixtures deterministically
```

No ASan (broken on this Mac, as in M2–M4).

## The synthetic mini-model

`tools/oracle.py` `MINI_CFG` — the tests/m0 fixture dims (hidden 128;
GDN 8 V heads / 4 K heads × 32, conv k=4; full attn 4 q / 2 KV heads ×
head_dim 64, partial rotary 16 (factor 0.25), θ=1e7; MoE 16 experts
top-4, moe_inter 32, shared 32; vocab 256) with the 2-layer schedule
`layer_types = ["linear_attention", "full_attention"]` — one layer of
each kind, MoE on both (the real model has MoE on ALL layers).

The container uses the REAL M1 output schema (tools/convert.py):

- dense tensors under their HF names (`model.language_model.*`,
  `lm_head.weight`);
- the fused expert tensors SLICED per expert into the synthesized
  2-member slab names
  `model.language_model.layers.{L}.mlp.experts.{E}.{gate_up_proj,
  down_proj}.weight`, written gate_up-then-down contiguously per expert
  (the real slab layout);
- `model.safetensors.index.json` (the standard index `c/st.h` reads);
- `config.json` with the nested `text_config` schema
  (reference/config.json in miniature) — including decorative real keys
  the loader must ignore (`attn_output_gate`, `mamba_ssm_dtype`,
  `router_aux_loss_coef`, `use_cache`, vision_config) and
  `mtp_num_hidden_layers: 1` with NO mtp tensors: the default load must
  tolerate the mtp shard group's absence (MTP is M8).

Container = one safetensors shard + index + config (tests/m1/stutil.py
writer), loaded by the C side through the real `c/st.h` path. Master
seed 20260831 (the m0 seed: clean router top-k margins); sampled
uniforms PCG64 seed 20260805. The golden path consumes ONLY weights read
back from the container (per-expert slices restacked into the fused
oracle names — from disk bytes, never the generation arrays; the Apus
M4c lesson).

Golden sequences (f32 = C target, f64 = truth; chains generated by
iterative one-shot prefills, the Apus M5 lesson):

- `prefill6` / `prefill64` — per-position logits [T, 256].
- `dec32` — prefill 32 + 8 decode steps with carried state, fixed ids,
  per-step logits (decode-vs-decode coverage; the oracle is chunk-exact,
  so these goldens are as clean as the prefill ones).
- `greedy` — 16-step greedy continuation of a 24-token context: tokens,
  per-step teacher-forced logits, top1−top2 gap.
- `sampled` — 16 steps at temp 0.6 / top_k 20 / top_p 0.95: tokens,
  teacher-forced logits, consumed uniforms, CDF margin per step.
- `trace` — hidden state after each layer on the greedy chain context
  (both modes) + `envelope.txt`.
- `cli_greedy.txt` — the 8-token greedy stream for the Makefile CLI
  smoke (diffed, not just line-counted).

## Sampling rules (pinned by the oracle, implemented by c/sample.h)

argmax = lowest index on exact ties; FP32 max-subtracted softmax of
logits/temp; **top-k first** (HF warper order): keep the k
highest-probability tokens, stable on exact ties; then top-p nucleus:
keep token i iff `cumsum_before_i <= top_p` (HF shift rule),
renormalize, draw the smallest CDF entry > u. splitmix64 RNG (CLI
`--seed`); temp ≤ 0 = greedy (`--greedy`). CLI defaults are the Qwen
generation_config defaults: temp 1.0, top_p 0.95, top_k 20
(presence_penalty is M7).

## Measured results (this MacBook Pro M1, `make test-m5`)

rel = max|C−f32|/max|f32|; env = the same ratio for |f32−f64|. Gate per
sequence: rel ≤ 2·env + 0.01 and argmax-flip ≤ env-flip + 5%.

| sequence | C-vs-f32 rel | envelope rel | C flips | env flips |
|---|---|---|---|---|
| prefill6 | 0.0049 | 0.012 | 0% | 0% |
| prefill64 | 0.025 | 0.034 | 0% | 1.6% |
| dec32 (worst step) | 0.0065 | — | 0/8 | — |
| greedy teacher-forced (worst) | 0.0071 | — | 0/16 | — |
| sampled teacher-forced | — | — | 1/16 (margin ≤ 2e-2) | — |

Divergence budget (per-layer hidden, teacher-forced greedy chain, 40
tokens):

| stage | C-vs-f32 rel | f32-vs-f64 rel |
|---|---|---|
| h after L0 (gdn) | 0.0021 | 0.044 |
| h after L1 (full) | 0.0053 | 0.046 |
| logits (envelope) | — | 0.066 |

**C is well inside the f32-vs-f64 envelope at every stage** — the
residual is fp32 accumulation-order noise (C sequential vs the oracle's
f64-accumulated ideal realization) cascading through the same bf16
rounding points the envelope measures; no semantic error anywhere.

**Greedy token stream (teacher-forced)**: 0/16 flips, 0 unexcused
(policy: a flip would be excused iff golden gap ≤ 0.5).
**Sampled token stream (replayed uniforms)**: 1/16 flip, excused — CDF
margin ≤ 2e-2 (per-token probs are ~4e-3 at vocab 256; boundary shifts
of that size follow from the logit divergence). Policy: excused iff
margin ≤ 2e-2; **0 unexcused**. This verifies the c/sample.h rules
against the oracle's; it is not a statistical-distribution check.

**Chunk invariance**: prefill(64) vs prefill(40) + 24 single decodes —
64×256 logits **bitwise identical** (the one per-token body, as in
M4c). **Determinism**: repeated prefill bitwise identical. Digest
`29a4612f3057cac2` identical at APUS_THREADS=1/4/8 (the Makefile diffs
stdout) and between the -O2 and UBSan builds.

## CLI

```
bin/apus-qwen run --model DIR [--prompt "text" | --ids "1,2,3"]
    [--max-tokens N] [--seed S] [--temp T] [--top-p P] [--top-k K]
    [--greedy] [--max-seq N]
```

`--prompt` renders the Qwen ChatML template (c/encoding.h) and
tokenizes via DIR/tokenizer.json (c/tok.h); `--ids` feeds raw ids
(fixture model). Sampling defaults temp 1.0 / top_p 0.95 / top_k 20
(reference/generation_config.json). Prints generated ids (decoded text
with a tokenizer) + prefill/decode tok/s. Smoke (in `make test-m5`): 8
greedy tokens from the fixture model — `186 26 88 97 193 139 54 229`,
diffed against the oracle golden `fixtures/cli_greedy.txt`.

## M6 (tiering) readiness

- Loader opens `model.safetensors.index.json` via `ApusStSet` (lazy
  shard open, per-tensor pread materialization). Embed/head/norms are
  zero-copy views into the shard payloads; all dims are config-driven
  (the real 40-layer/2048-hidden/256-expert config parses through the
  same code path; the fixture uses the real schema, nested text_config
  and all).
- **Expert-store insertion point**: the per-expert resolution loop in
  `apus_model_load_ex` (marked in c/model.h) is the single expert-aware
  place — eager mode copies the M1 2-member slab slices
  (`...experts.{E}.gate_up_proj.weight` [2I,H] + `.down_proj.weight`
  [H,I]) into owned contiguous arrays (`ApusLayerW.exp_gu/exp_d`; the
  slab slice IS the fused gate_up layout — plain concat, no repack).
  M6 swaps this for lazy slab views via the store without touching the
  forward path. `c/cache.h` is still a v1 (3-member slab) consumer —
  teaching it the v2 2-member slab is M6's job (M1 status entry).
- Known M5-era performance debt (M6+/perf milestones): the prefill is
  the sequential per-token body (the Ling M6c/M9c batched prefill is
  deferred), VLAs on the logits path, KV caches sized max_seq×nkv×d per
  full layer eagerly.
- Missing for the real container: `weights/` download is in explicit
  WAIT (gate 8); golden-token comparison against the reference on fixed
  prompts/seeds; MTP block (M8); real-model memory behaviour at 40
  layers (S is 32×128×128 fp32 = 2 MB per GDN layer, caches scale with
  max_seq).
